## 📚 Modules Covered

| # | Module | Content |
|---|--------|---------|
| 01 | What is Phishing? | Definition, how it works, who is targeted |
| 02 | Types of Attacks | Email, Spear, Smishing, Vishing, Clone, Whaling |
| 03 | Email Anatomy | Interactive annotated phishing email with red flags |
| 04 | How to Spot Phishing | 8 red flags with detailed explanations |
| 05 | Social Engineering | Urgency, Authority, Fear, Curiosity, Greed tactics |
| 06 | Real-World Cases | Google/Facebook $100M scam, PayPal campaign, COVID wave |
| 07 | Best Practices | 7 protective measures everyone should follow |
| 08 | Interactive Quiz | 5 scenario-based questions with instant feedback |

## ✨ Features

- 🎨 Dark-themed professional UI
- 📱 Fully responsive (mobile + desktop)
- 🧠 Interactive 5-question quiz with scoring
- 🔍 Annotated fake phishing email with hover tooltips
- 📊 Progress bar tracking your position
- 🎞️ Scroll-based reveal animations
- 📖 Real-world phishing case studies
